# DalilDZ Roadmap

Roadmap items are not claims of existing functionality.

## Implemented baseline

- evidence/status domain model
- PostgreSQL persistence and historical analysis jobs
- PDF/image ingestion and provenance
- Arabic/French/Latin normalization
- entity resolution
- public website metadata
- DNS/TLS/RDAP technical evidence
- manual official-source evidence path
- JSON/CSV/printable HTML reports
- CSV/XLSX vendor import
- Next.js trilingual UI
- CLI
- MCP server
- Redis/Celery worker
- CI, CodeQL and dependency audits

## Near term

- broaden deterministic document templates/labels
- dedicated OCR Docker profile with tested CPU runtime
- PDF report generation
- richer case filtering/search
- stronger DNS-rebinding resistance with network-layer egress policy examples
- source freshness policies and OUTDATED automation
- more Arabic/French evaluation data

## Later

- pluggable authentication/organization boundary
- reviewer notes/approvals
- source-specific caching policies
- additional Algerian public sources where lawful documented access exists
- PostgreSQL pg_trgm-assisted candidate retrieval at larger scale
