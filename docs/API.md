# REST API

The authoritative interactive specification is generated by FastAPI at `/docs` and `/openapi.json`.

## Cases

- `GET /api/v1/cases` — paginated case list
- `POST /api/v1/cases` — create case
- `GET /api/v1/cases/{id}`
- `PATCH /api/v1/cases/{id}`
- `DELETE /api/v1/cases/{id}`
- `POST /api/v1/cases/{id}/claims`

## Documents and evidence

- `GET /api/v1/cases/{id}/documents`
- `POST /api/v1/cases/{id}/documents`
- `POST /api/v1/cases/{id}/manual-evidence`
- `GET /api/v1/cases/{id}/evidence`
- `GET /api/v1/cases/{id}/checks`
- `GET /api/v1/cases/{id}/timeline`

## Analysis

- `POST /api/v1/cases/{id}/analyze` — synchronous
- `POST /api/v1/cases/{id}/analyze/background` — Celery queue
- `POST /api/v1/cases/{id}/refresh`
- `GET /api/v1/cases/{id}/jobs`

## Reports

- `GET /api/v1/cases/{id}/report`
- `GET /api/v1/cases/{id}/report.csv`
- `GET /api/v1/cases/{id}/report.html`

## Utilities

- `POST /api/v1/entity-resolution`
- `POST /api/v1/bulk/import`
- `GET /api/v1/sources`
- `GET /api/v1/sources/health`
- `GET /api/v1/health`

## Errors

Business errors use an explicit code inside the FastAPI error detail, for example:
`CASE_NOT_FOUND`, `FILE_TOO_LARGE`, `UNSUPPORTED_FILE_TYPE`, `OCR_FAILED`, `QUEUE_UNAVAILABLE`.

Raw Python stack traces are not returned intentionally.
